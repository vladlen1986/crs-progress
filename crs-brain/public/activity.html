Activity log

Every action you and the copilot take — timestamped. Search it, or ask the Buildprint chat to find when something happened and roll the test branch back to a savepoint taken before it.
How rollback works. A savepoint is taken before every savepoint apply, so this log is the index of restore points. Click ⟲ Roll back on any action to open a Buildprint chat that will find the right savepoint and restore the test branch to just before it. Note: savepoint-restore reverts app structure & workflows — it does not undo database record writes (created/edited Things), which have to be removed in Bubble or via a Bubble data backup.
