# Master QA checklist

This file is the program's memory. It is the permanent regression suite for the CRS Brain app: every verifiable behavior shipped by phases P1–P11, one row each. The file is **append-only** — new phases append rows; existing rows are never deleted (superseded rows are how history stays honest). QA runs update only `status` (UNTESTED / PASS / FAIL / BLOCKED / N-A), `last-run` (date), and `evidence` (what was observed, with refs). Near-identical rows from overlapping phases were de-duplicated at creation, keeping the more specific row (dropped: P2-explorer-base.6 → P3-explorer-fix1.4, P2-explorer-base.7 → P3-explorer-fix1.3/P5-explorer-fix3.3/P3-explorer-fix1.13, P8-sounds-wishlist.3 → P10-notify-sync.4, P3-explorer-fix1.12 → P9-os-grade.5).
