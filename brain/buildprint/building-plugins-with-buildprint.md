# Building plugins with Buildprint
> Source: https://docs.buildprint.ai/building-plugins-with-buildprint-mnih2 · Captured: 2026-07-14

Buildprint enables you to build Bubble plugins with AI. Buildprint is able to do anything in the plugin editor, including building entire new features.

## How to use it

Create a new plugin project and connect your plugin (see [creating-a-plugin-project.md](creating-a-plugin-project.md)).

"Plugins are cloned into a codebase that your agent can work on and send back to Bubble." This includes plugin metadata like name, icon, and description.

Similar to Buildprint Bubble app projects, you can ask your agent to review the project and implement any desired changes.

## Limitations

- Buildprint cannot publish plugins directly — you must complete this final step manually in the editor, though helpful instructions will be provided.
- Buildprint cannot create a new empty plugin independently; you must first create it in Bubble before connecting the project.
