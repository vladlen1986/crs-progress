# Building plugins with Buildprint
> Source: https://docs.buildprint.ai/building-plugins-with-buildprint-mnih2 · Captured: 2026-07-14 (verbatim .md)

Buildprint enables you to build Bubble plugins with AI. Buildprint is able to do anything in the plugin editor, including building entire new features.

## How to use it

Create a new plugin project and connect your plugin. For more information, see [**here**](https://docs.buildprint.ai/creating-a-plugin-project-oksex).

Plugins are cloned into a codebase that your agent can work on and send back to Bubble. This includes plugin metadata like name, icon, and description.

Like with Buildprint Bubble app projects, you can ask your agent to check out the project and make any changes you'd like.

## Limitations

Currently, Buildprint is unable to publish plugins (you'll need to do the final step in the editor), but will give you helpful instructions for how to do this.

Buildprint also cannot create a new empty plugin itself - you'll need to do this in Bubble, and then connect the project.
