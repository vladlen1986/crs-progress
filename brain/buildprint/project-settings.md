# Project settings
> Source: https://docs.buildprint.ai/project-settings-h1nyt · Captured: 2026-07-14

Project settings manage a project's identity, Bubble connection details, AI guidance, and project access.

## Open project settings

1. Open the project.
2. Use the project menu or project navigation to open Settings.

"Workspace admins and project Admins can change project settings. Other project members may see settings in a read-only state."

## Settings sections

- **General**: modify the project logo, name, URL slug, Bubble App ID, primary domain, run-mode credentials, collaborator permissions, and app summary. "Once app ownership is verified, the Bubble App ID is locked to that project."
- **Members**: add workspace members, send email invitations, adjust project roles, remove collaborators, and review pending project invites.
- **Style**: configure project-specific style preferences for naming, UI patterns, implementation constraints, or review standards. "Buildprint includes this guidance when AI works on the project."

## Project roles

- **Admin**: manage project settings, members, invitations, and Build mode.
- **Member**: work in the project, use Build mode, chat, and see project members.
- **Guest**: use Build mode and chat without broader workspace access.
- **Read-only**: read project context and participate in Plan-mode chat, but cannot access Build mode.

"Workspace admins have implicit project Admin access."

## Danger Zone

- **Move to another workspace**: transfer the project to a different workspace. "You must be a workspace admin in the source workspace and at least a member in the destination workspace."
- **Disconnect Buildprint**: remove the Buildprint collaborator from the Bubble app. You may retain Buildprint project data for later reconnection or remove all data. "Disconnecting does not delete or change the Bubble app itself."
