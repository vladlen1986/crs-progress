# Sharing chats
> Source: https://docs.buildprint.ai/sharing-chats-n9ro8 · Captured: 2026-07-14

Buildprint conversations can be shared with project collaborators or via a read-only public link.

## Add conversation members

The conversation owner has sole authority to add or remove participants. Any added person must have active workspace membership and project access.

To add a member:

1. Open the conversation.
2. Click Share.
3. Choose a project teammate.
4. Click Add.

Added members can view the conversation and send messages in the thread. The owner can remove them at any time. Non-owner members can leave the conversation.

Shared conversations run with the **conversation owner's** connected AI provider credentials. For Buildprint-billed models, availability is checked against the workspace's Buildprint AI credits.

## Public links

The owner can create a public link for read-only access:

1. Open the conversation.
2. Click Share.
3. In Public link, click Create link.
4. Copy the generated link.

Anyone with the link can view the conversation read-only — they cannot send messages or interact with the agent.

The owner can regenerate a public link to invalidate the previous link, or revoke public sharing entirely.

## Private access rules

To open a conversation inside Buildprint, a user needs ALL of:

- Active access to the workspace.
- Access to the conversation's project.
- Access to the conversation as the owner or an added member.

Workspace admins can access every project, but they still must be the conversation owner or an added conversation member to open a private conversation.
