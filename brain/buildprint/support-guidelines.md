# Support guidelines
> Source: https://docs.buildprint.ai/support-guidelines-gt7lu · Captured: 2026-07-14 (verbatim .md)

Buildprint is in beta. Some things will be rough, and we do not guarantee uptime, availability, or a specific service level.

Before contacting support, check the documentation first. You can also ask AI to help search or explain the docs if that is faster.

## Email support

You can contact support at `support@getbuildprints.com` or via the support form in our help desk chatbot. Please use the help desk at first instance.

Support response time is approximately 96 hours. Due to request volume, we may not be able to respond when the answer is already available in the documentation.

## Bubble Forum

You will usually get the quickest response in the Bubble Forum thread.

Other Buildprint users and Bubble community members may be able to help before our team can respond.

## Things we cannot help with

We cannot help with:

- Setting up MCP servers.
- Minor editing issues that can be fixed directly in Bubble or through normal AI-assisted development.
- Buildprint not doing exactly what you asked. Read the docs and best practices to learn how to prompt Buildprint effectively.
- Issues connecting your app when the setup docs have not been followed. Check that your Bubble app ID is valid and that the collaborator was invited with the correct permissions.

## Things we can help with

We can help with:

- Irrecoverable Buildprint errors or broken editor states caused by Buildprint edits.
- Deployment errors caused by Buildprint edits.
- Questions that are not answered in the documentation.
- Feature requests.
