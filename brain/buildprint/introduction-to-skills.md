# Introduction to skills
> Source: https://docs.buildprint.ai/introduction-to-skills-mq7pq · Captured: 2026-07-14 (verbatim .md)

Skills are reusable instructions for Buildprint agents.

They are useful when you want an agent to follow the same checklist or process repeatedly, such as testing a change, reviewing privacy rules, documenting a feature, or following your team's Bubble conventions.

## How skills work

A skill is included with an agent message. The agent reads the skill instructions as extra context for that turn.

In the chat composer, type / or @ to open the command menu and select a skill. Skills appear as Buildprint skill chips in the message.

## Skill scopes

Buildprint has three skill scopes.

- Official skills are managed by Buildprint and available automatically.
- Workspace skills are available across the workspace.
- Project skills are available when their owning project is selected.

## When to create a skill

Create a skill when you repeat the same instructions often.

Good examples include:

- Test this change in run mode.
- Review this branch for privacy rule risks.
- Document what changed for a teammate.
- Follow our team's page layout conventions.

## Keep skills safe

Do not put secrets, credentials, API keys, cookies, private tokens, or sensitive customer data in skills.
