# Inviting clients
> Source: https://docs.buildprint.ai/inviting-clients-u4fo2 · Captured: 2026-07-14

You can invite clients to a specific project without giving them access to other client work in your workspace.

## Invite from project settings

1. Open the client's project.
2. Go to Settings > Members.
3. Click Add a member.
4. Enter the client's email address.
5. Choose a project role.
6. Send the invite.

Most common roles for clients:

- **Read-only**: view project context and participate in Plan-mode chat, but cannot use Build mode.
- **Guest**: use Build mode and chat in this project without broader workspace access.
- **Member**: work in the project like an internal project member.

When someone accepts a project-only invite, Buildprint gives them limited workspace Guest access so they can open that project. They do not become a full workspace Member unless invited to the workspace separately.

## What project clients can see

A project-scoped client can see the project they were added to and project areas their role allows, such as conversations, reviews, logs, tests, and settings in read-only form where applicable.

They cannot see other projects unless added to those projects. They do not get workspace admin settings. In workspace member lists, non-admins only see people who share a project with them.

## Give access to another project

Workspace admins can grant a client access to more projects later:

1. Go to Workspace settings > Members.
2. Find the client.
3. Choose Manage projects.
4. Check the additional projects.
5. Save changes.

Project admins can also invite the client directly from another project's member settings.

## Sharing conversations with clients

Use conversation sharing when you only need to show one thread:

- **Add as conversation member**: the client must already have Buildprint access to the project. They can read and send messages in that conversation.
- **Public link**: anyone with the link can view the conversation read-only from a browser. The conversation owner can regenerate or revoke the link.
