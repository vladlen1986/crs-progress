# Choosing a model
> Source: https://docs.buildprint.ai/choosing-a-model-cjqs5 · Captured: 2026-07-14

Buildprint supports multiple AI providers and model families. The available models change over time, so use the model picker in the chat composer as the current source of truth.

> TIP: "The all-around best model and best value option for Buildprint users is currently OpenAI's ChatGPT/Codex plans, which start at $20/mo."

## Providers

Depending on your workspace configuration, Buildprint can use:

- Buildprint-managed models.
- OpenAI or ChatGPT-connected models.
- Claude-connected models.
- Gemini-connected models.
- OpenRouter bring-your-own-key

Each team member may need to connect their own provider account unless your workspace is using a shared provider or Buildprint-managed credits.

## Current model guidance

Use the model picker labels as the source of truth for:

- Whether a model supports building.
- Whether it is recommended for planning, building, UI work, or browser testing.
- Provider connection requirements.
- Cost or credit behavior.
- Any model-specific limitations.

As of now, Buildprint supports OpenAI, Claude, Gemini, OpenRouter, and Buildprint-managed options, including both editing-capable and planning-only models.

## Cost

Costs depend on provider, model, workspace billing, and whether you use your own provider subscription or Buildprint-managed credits.

For predictable usage, connect the provider account your team already uses or choose a Buildprint-managed model whose credit behavior you understand. For heavy Build mode work, monitor usage in the provider or billing UI.
