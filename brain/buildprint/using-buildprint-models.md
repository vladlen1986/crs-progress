# Using Buildprint models
> Source: https://docs.buildprint.ai/using-buildprint-models-3zmc7 · Captured: 2026-07-14

Buildprint models enable users to leverage Buildprint agents without requiring personal subscriptions to Claude, ChatGPT/Codex, or Gemini.

## How it works

Buildprint models operate on a pay-as-you-go basis through Buildprint credits. Each workspace receives a monthly allocation of Buildprint AI credit, currently "$5 per month of included Buildprint AI credit." Connecting your own AI subscription bypasses these credits entirely. If an OpenRouter key is connected to your workspace, it will be used for Buildprint model traffic instead of consuming credits.

## When to use Buildprint models

This option suits users who:

- Prefer not to connect a separate AI subscription
- Need an alternative model for occasional agent work
- Want centralized usage tracking via Buildprint credits
- Plan to route Buildprint model traffic through a workspace OpenRouter key

Heavy usage scenarios may benefit from connecting your own subscription or OpenRouter key for improved billing and limit management.

## Add credits

1. Navigate to Agent → Integrations → AI Providers
2. Locate the Buildprint provider card
3. Select **Add credits**

Monitor AI credit consumption in Workspace settings → Billing.

## Credit errors

When credits deplete, Buildprint prompts users to "connect ChatGPT, Claude, Gemini, or OpenRouter, or add credits before continuing."
