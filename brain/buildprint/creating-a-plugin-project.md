# Creating a plugin project
> Source: https://docs.buildprint.ai/creating-a-plugin-project-oksex · Captured: 2026-07-14 (verbatim .md)

Buildprint supports building Bubble plugins with AI. There are two types of projects in Buildprint - apps (Bubble apps), and plugins. Plugins do not count as billable projects.

## Create a new project

Begin by creating a new project in your workspace. Select the "Plugin" project type.

Enter the plugin name, and paste the Bubble plugin editor URL for this plugin.

> [!INFO]
> You need to create the plugin in Bubble yourself. If you need assistance with this, then please follow [**this**](https://docs.buildprint.ai/creating-a-plugin-in-bubble-caiph) guide.

![Image](https://static.ferndesk.com/user-images/file_01KWP7Y2MRPJV1839DN2CX8QEC.png)

## Invite Buildprint to the plugin editor

Invite `connect@getbuildprints.com` to the plugin editor, so that Buildprint can work on your plugin.

![Image](https://static.ferndesk.com/user-images/file_01KWP85WZ8669QQ514PW6STZJF.png)

## Verify plugin ownership

Buildprint requires you verify ownership of the plugin by adding an HTML tag to the header. You can remove this after verification.

![Image](https://static.ferndesk.com/user-images/file_01KWP86TPCH2Y8EYNTB1K8R831.png)

![Image](https://static.ferndesk.com/user-images/file_01KWP88SR76CQ3APBAMBSG1MGK.png)

## Begin building with Buildprint

Buildprint is now connected to your plugin. Buildprint can make any changes to your plugin. Chat with your plugin project like you would any other project. When actively building, it's recommended you connect the plugin to a test app so that Buildprint can test its own work in the browser.
