# Visual elements
> Source: https://manual.bubble.io/core-resources/elements/native-mobile-elements/visual-elements · Captured: 2026-07-14 (verbatim from manual.bubble.io llms-full.txt)

## Web view

Displays a page from your own app inside a mobile element. Supports responsive settings. Users can’t navigate to other pages from within the web view, so include all needed content on a single page. External URLs are not supported. Only works in the BubbleGo app (not Web Preview).

### Disable zoom

Prevents pinch-to-zoom inside the Web View and Scrollable View elements. Enabled by default. Can be turned off in the element’s properties.
