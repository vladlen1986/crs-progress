### Duplicated `bptheme` condition on element `bUoGr` (18x, page `index`)

- **PROPOSED fix (not applied):** Do not touch the theming mechanism itself (that would reopen a locked decision). Instead, verify each of the 18 occurrences is a distinct element's own single `bptheme`-swap conditional (compliant, just repetitive across the page — same fix as above: hoist to a Group state if these are siblings/descendants) versus an accidental duplication of the *same* condition object on one element or a direct `Current User's dark_theme` expression bypassing `bptheme` — the latter would violate §3.2's "one condition per element via bptheme" rule and needs correction back to the standing pattern, not a redesign.
