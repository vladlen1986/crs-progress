# Automated tests
> Source: https://manual.bubble.io/help-guides/security/security-dashboard/security-tests/automated-tests · Captured: 2026-07-14 (verbatim from manual.bubble.io llms-full.txt)

{% hint style="info" %}
Settings applied in the *Test settings* popup also apply to automated tests.

Article: [Test settings](/help-guides/security/security-dashboard/security-tests/test-settings)
{% endhint %}

Automated tests enable you to run security tests automatically, with two different trigger options:

* Automatic test on deploy: this will automatically perform a test whenever your app is deployed to live.
* Scheduled tests: this option lets you set up automated tests on a set schedule (such as daily/weekly/monthly).
